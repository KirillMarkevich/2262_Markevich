### Задание 1 **(2)**
*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if x[i] < i or x[i] > 2*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.


**Решение:**
```python
x = [int(t) for t in input().split()]
i = 0
while i < len(x) and x[i] >= i and x[i] <= 2 * i:
    i += 1
print(i)
```

Цикл `for` из исходного решения прерывается, если `x[i] < i` или `x[i] > 2 * i`. Следовательно, цикл `while` должен продолжаться при обратном условии: `i <= x[i] <= 2 * i`. Дополнительно проверяется `i < len(x)`, чтобы не обратиться к элементу за пределами списка. Если ни одно условие остановки не встретилось, `i` увеличится до длины списка. Например, при вводе `0 1 3 5 20` программа выведет `4`: на индексе `4` число `20` больше `2 * 4`, поэтому цикл остановится.


### Задание 2 **(2)**
*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if i <= x[i] < 2*i or 3*i <= x[i] < 4*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.


**Решение:**
```python
x = [int(t) for t in input().split()]
i = 0
while (i < len(x)
       and (x[i] < i or x[i] >= 2 * i)
       and (x[i] < 3 * i or x[i] >= 4 * i)):
    i += 1
print(i)
```

Исходный цикл останавливается, когда выполняется хотя бы одно из условий: `i <= x[i] < 2 * i` или `3 * i <= x[i] < 4 * i`. В `while` записано условие продолжения — оба этих диапазона должны быть исключены. Поэтому используются выражения `x[i] < i or x[i] >= 2 * i` и `x[i] < 3 * i or x[i] >= 4 * i`. Проверка `i < len(x)` не позволяет выйти за границы списка. Когда элемент попадает в один из заданных диапазонов либо список заканчивается, цикл прекращается, и выводится текущий индекс `i`.


### Задание 3 **(2)**

*Напишите пример программы на* **Java** *с двумя вложенными циклами и инструкцией* **break** *для выхода
из двух вложенных циклов. В качестве такой программы можно взять поиск первого нуля в двумерном массиве.*


**Решение:**
```java
public class Main {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 0, 6},
            {7, 8, 9}
        };

        search:
        for (int i = 0; i < a.length; i++) {
            for (int j = 0; j < a[i].length; j++) {
                if (a[i][j] == 0) {
                    System.out.println("Ноль найден: [" + i + "][" + j + "]");
                    break search;
                }
            }
        }
    }
}
```

Внешний цикл перебирает строки двумерного массива, а внутренний — элементы каждой строки. Когда найден элемент `0`, программа печатает его координаты. Метка `search` указывает на внешний цикл, поэтому команда `break search` завершает сразу оба цикла, а не только внутренний.


### Задание 4 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = list(range(10))
b = [a.pop() - x for x in a]
print(*b)
```
*Объясните, почему список* **b** *получился именно таким.*


**Решение:**

Изначально `a = [0, 1, 2, ..., 9]`. Итератор списка в выражении `[a.pop() - x for x in a]` проходит по списку. При каждом шаге генератора сначала вызывается `a.pop()`: он удаляет и возвращает последний элемент списка `a`. Затем из этого значения вычитается текущий элемент `x`, по которому проходит итератор. Поэтому вычисляются выражения `9 - 0`, `8 - 1`, `7 - 2`, `6 - 3`, `5 - 4`. Список сокращается во время обхода, поэтому выполняется только пять итераций.

1 шаг: x = 0, pop удаляет 9, 9 - 0 = 9
2 шаг: x = 1, pop удаляет 8, 8 - 1 = 7
3 шаг: x = 2, pop удаляет 7, 7 - 2 = 5
4 шаг: x = 3, pop удаляет 6, 6 - 3 = 3
5 шаг: x = 4, pop удаляет 5, 5 - 4 = 1

В результате `b` равен:
```
9, 7, 5, 3, 1
```


### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*


**Решение:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> v(n);
    for (auto &x : v) {
        cin >> x;
    }

    if (!v.empty()) {
        const long long last = v.back();
        for (auto &x : v) {
            x += last;
        }
    }

    int positive = 0;
    int negative = 0;
    for (const auto &x : v) {
        if (x > 0) ++positive;
        else if (x < 0) ++negative;
    }

    cout << "Положительных: " << positive << '\n';
    cout << "Отрицательных: " << negative << '\n';
    return 0;
}
```

Сначала вводится размер вектора `n`, затем первый цикл по коллекции считывает все его элементы. Если вектор не пуст, `v.back()` сохраняет последнее значение в переменной `last`; второй цикл добавляет это значение к каждому элементу. После изменения третий цикл проверяет элементы: при `x > 0` увеличивается счётчик положительных, при `x < 0` — отрицательных. Нулевые элементы не относятся ни к одной из этих категорий. В конце выводятся оба счётчика.


### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*


**Решение:**

Два основных различия:

1. `from` и `to` вычисляются один раз при создании `__i` и `__n`. В обычном цикле `for (int i = from; i < to; ++i)` выражение `to` проверяется заново при каждой проверке условия.
2. В `forc` переменная `i` объявлена как `const int&`, то есть является константной ссылкой на внутреннюю переменную `__i`. Изменять `i` напрямую нельзя, тогда как обычный счётчик `for` можно изменять.

**Программа 1 — отличие в вычислении верхней границы:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int to = 3;
    {
        int __i = 0, __n = to;
        for (const int &i = __i; i < __n; __i++) {
            cout << i << ' ';
            --to;
        }
    }
    cout << '\n';
}
```
Вывод: `0 1 2`, потому что `__n` сохраняет начальное значение `3`.

Для сравнения, обычный цикл:
```cpp
#include <iostream>
using namespace std;

int main() {
    int to = 3;
    for (int i = 0; i < to; ++i) {
        cout << i << ' ';
        --to;
    }
    cout << '\n';
}
```
Вывод: `0 1`. В обычном цикле значение `to` меняется и повторно проверяется на каждой итерации.

**Программа 2 — отличие в изменяемости счётчика:**
```cpp
int to = 5;
{
    int __i = 0, __n = to;
    for (const int &i = __i; i < __n; __i++) {
        ++i;
    }
}
```
В обычном цикле `for` выражение `++i` внутри тела допустимо.

В первой паре программ переменная `to` уменьшается на каждой итерации. В варианте `forc` верхняя граница заранее копируется в `__n`, поэтому изменения `to` не влияют на число итераций: счётчик доходит до `3`. В обычном `for` условие каждый раз сравнивает `i` с текущим `to`, поэтому после уменьшения границы цикл заканчивается раньше и выводит только `0 1`. Во второй демонстрации `i` в `forc` является константной ссылкой на `__i`, поэтому присваивать ей новое значение или выполнять `++i` нельзя. В обычном цикле `for` счётчик — отдельная изменяемая переменная, и его можно менять в теле цикла.


### Задание 7 **(2)**

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной 
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*


**Решение:**

**Python**
```python
numbers = [int(x) for x in input().split()]

for x in numbers:
    if x < 0:
        print("Найдено отрицательное число:", x)
        break
else:
    print("Все числа неотрицательные")
```

**C++**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> numbers(n);

    for (int &x : numbers) {
        cin >> x;
    }

    bool found = false;
    for (int x : numbers) {
        if (x < 0) {
            cout << "Найдено отрицательное число: " << x << '\n';
            found = true;
            break;
        }
    }

    if (!found) {
        cout << "Все числа неотрицательные\n";
    }
    return 0;
}
```
В Python цикл перебирает числа по порядку. При обнаружении первого отрицательного числа оно выводится, после чего `break` прекращает перебор. Если цикл завершился без `break`, выполняется блок `else` и выводится сообщение, что все числа неотрицательные. В C++ выполняется тот же поиск, но результат запоминается в переменной `found`: она становится `true`, если отрицательное число найдено. После цикла сообщение об отсутствии отрицательных чисел выводится только при `found == false`.


### Задание 8 **(2)**

*Рассмотрим следующую программу.* 
```
if x>=5 and y>=-5:
   print(0):
elif x<0 or y<0:
   print(1):
else:
   print(2):
```
*Опишите множества значений при которых программа выводит 0, 1 и 2. Например,*

A={ (x,y)| x ∈ [5;∞), y ∈ [-5;∞)}


**Решение:**

- `A = {(x, y) | x ∈ [5; ∞), y ∈ [-5; ∞)}` — программа выводит `0`.
- `B = {(x, y) | (x < 0 или y < 0) и (x < 5 или y < -5)}` — программа выводит `1`. Вторая часть условия означает, что первая ветка `if` не сработала.
- `C = {(x, y) | x ≥ 0, y ≥ 0 и (x < 5 или y < -5)}` — программа выводит `2`.

Первая ветка `if` проверяется раньше остальных: если одновременно `x ≥ 5` и `y ≥ -5`, выводится `0`. Ветка `elif` рассматривается только тогда, когда первое условие ложно; если при этом `x < 0` или `y < 0`, выводится `1`. Во всех оставшихся случаях выводится `2`. Поэтому для множества `B` обязательно учитывать, что условие первой ветки не выполнено, а для множества `C` — что не выполнены ни первая, ни вторая ветки.
